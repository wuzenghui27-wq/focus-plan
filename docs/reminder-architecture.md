# 提醒系统架构

## 两种展示通道

### 网页内提醒

页面处于前台时使用。应用可以完全控制它的布局和交互：

- 手机端：顶部安全区下方滑入，支持向上滑动或点击关闭。
- 电脑端：左下角滑入。
- 最多显示三条，相同 `tag` 的提醒自动去重。

### 系统通知

页面进入后台时使用 `ServiceWorkerRegistration.showNotification()`。系统通知由操作系统渲染，
网页不能指定它在屏幕上的具体位置。点击通知会聚焦已有页面或打开计划页。

## 代码分层

- `reminder-tools.js`：计算提醒时间，判断计划是否到期。
- `reminder-presenter.js`：网页提醒的位置、队列、动画和滑动关闭。
- `script.js`：选择网页内提醒或系统通知，并更新计划的提醒状态。
- `service-worker.js`：后台系统通知的点击行为。

## 当前限制

当前本地应用依靠页面定时检查计划。页面完全关闭后，JavaScript 计时器不会继续运行。要实现
关闭页面后仍能准时提醒，需要在正式服务器中保存提醒任务，并使用 Web Push 将消息发送到
设备的 Service Worker。
