# Timer sound assets

These three WAV files come from
[Calinou/kenney-ui-audio](https://github.com/Calinou/kenney-ui-audio),
which packages Kenney's UI Audio assets:

- `focus-complete.wav` is the original `switch21.wav`.
- `short-break-complete.wav` is the original `switch30.wav`.
- `long-break-complete.wav` is the original `switch32.wav`.
